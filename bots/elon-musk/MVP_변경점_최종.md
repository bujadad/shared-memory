## 0. 한 줄 요약

기획안은 **자체 웹앱(Next.js+Supabase+결제연동)에 4개 라인업**을 올리는 그림이었으나,
실제 MVP는 **리틀리(링크인바이오) + 카카오 오픈채팅**이라는 노코드 최소 구성으로,
**2개 라인업(엔트리·코어)만 출시**했습니다.
핵심 방향(하이브리드=AI초안+전문가감수+음성+Q&A, 감수 처리량이 병목)은 그대로 유지됐고,
**"AI 속도"를 앞세우던 포지셔닝은 "전문가 감수"를 앞세우는 쪽으로 무게중심이 이동**했습니다.

## 2. 항목별 상세

### 2-1. 플랫폼 · 기술 스택 — 가장 큰 변화

**기획안**: `Next.js 웹 · Supabase · Claude/GPT API · Typecast · 토스/포트원`을 조합한 자체 웹서비스.
5단계 플로우(①폼→②AI초안→③본인검토→④음성+요약→⑤후속Q&A)를 웹 위에서 구현.

**실제 MVP**:
- **리틀리(link-in-bio)** 하나로 프로필·상품 진열·결제를 처리 → 자체 웹앱/DB 구축을 아예 건너뜀
- **카카오 오픈채팅**(https://open.kakao.com/o/gBxM9kAi)이 폼 접수·파일 전달·Q&A·환불문의 채널을 전부 겸함
- 결제는 리틀리 자체 결제 모듈

→ 기획안의 "전부 노코드/저코드"는 유지됐지만, 실제로는 **더 가볍게** 갔습니다. 웹 빌드 없이 링크인바이오 + 메신저만으로 유료 결제까지 도는 최소 루프를 먼저 세운 셈입니다. 병목(감수 처리량)이 웹 개발이 아니라 사람 손이었기 때문에, 개발에 시간을 쓰지 않은 판단이 방향과 일치합니다.

### 2-2. 상품 라인업 · 가격

**기획안**: 엔트리(14,900) → 코어(19,000~39,000) → 구독(월 9,900~19,000) → 부적(5,000~15,000), 4단 업셀 사다리.

**실제 MVP**: **엔트리·코어 2종만** 출시.

| 라인 | 구성 | 출시가 (~2026.09.30) | 정가 (예정) |
|---|---|---|---|
| 엔트리 | 개인 맞춤 운명 리포트 PDF (사주 명리 + 타로 해석) + 전문가 **검수** | **9,900원** | 30,000원 |
| 코어 하이브리드 | PDF + **음성 해설** + 전문가 **감수** + 후속 Q&A 1회 | **19,900원** | 50,000원 |

- **런칭 할인을 '엔트리'에 적용**한 결정. 코어(음성+감수)에 할인을 붙이면 ①가격 사다리 역전 ②앵커 과소 고정 ③감수 병목 폭주 위험 → 세 이유로 배제.
- 코어는 기획안 범위(19,000~39,000)의 **하단인 19,900으로 시작** — 전환율이 우선. 데이터 쌓이면 24,900~29,000으로 단계 인상 예정.

**실제 상품 상세 (라이브 기준)**

**1) [출시기념] 사주·타로 전문가 맞춤 리포트 (9,900원)**
- 개인 맞춤 운명 리포트 PDF (사주 명리 + 타로 해석)
- '명리·타로 이론 + 전문가가 구축한 해석 데이터 + 감수' (무검수 자동발송 X)
- 파일로 소장·재열람 가능
- 진행: 결제 → 간단 폼(생년월일시 + 고민 1~2가지) → AI 분석 → 전문가 검수·보완 → PDF 전달
- 납기: 영업일 기준 1~3일
- 정찰가 그대로, 추가·숨은 결제 없음

**2) 코어 하이브리드 (19,900원)**
- 구성: 리포트 + 목소리 해설 + 전문가 본인 감수 + 후속 Q&A 1회
- 납기: 2~4일

### 2-3. "영구 보관" 약속 철회

**기획안**: 차별화 5종 중 하나로 "결과물 영구 보관 — 내 운세 다시보기 아카이빙"을 명시.

**실제 MVP**: 산출물이 서버 호스팅이 아니라 **PDF 파일 전달**이라, 서버 아카이빙을 약속할 수 없어 **"파일로 소장·재열람"으로 문구를 정직하게 축소**했습니다.

### 2-4. 포지셔닝 · 카피 재프레이밍

**기획안**: 핵심 가치 3 = "전문가 품질 / **AI 속도** / 음성 차별화". AI 속도가 전면.

**실제 MVP**:
- **"AI 분석 + 전문가 검수"** 순서로, AI를 리드가 아니라 보조 도구로 배치. "9,900짜리 = 그냥 AI 일반론 아냐?"라는 품질 의심을 피하려는 의도.
- **"수만 명 실증 사례"류 정량 주장 배제** (광고법 리스크 + 브랜드 정합성). 차별화는 "명리·타로 이론 + 전문가가 구축한 해석 데이터"라는 정직한 문구로.
- 예언 단정 금지·"참고·심리 정리" 프레이밍·전상법 17조 환불 규정은 기획안 그대로 반영.

### 2-5. 산출물 제작 워크플로우

**기획안**: 폼→AI초안→검토→음성+요약을 API로 잇는 반자동 파이프라인.

**실제 MVP**: 주문이 들어오면 **수기 제작**. 확립된 실제 워크플로우는
`HTML 작성(heredoc) → WeasyPrint 렌더 → PDF 출력 → 검수`이며, Noto Serif/Sans CJK KR 폰트에 네이비·골드 브랜딩. 고급 리포트는 Canva/Figma로 디자인 폴리싱까지. 즉 **"made-to-order 수작업"**이 현재 실체이고, 자동 발송 파이프라인은 아직 없습니다.

## 3. 아직 구현/검증되지 않은 항목 (플래그)

기획안엔 있으나 **실제 MVP에서 아직 확인되지 않는** 항목입니다. 향후 정리 시 실제 상태로 갱신 필요:

- ⚠️ **무료 미니진단 랜딩+폼**: 기획안 4주차 핵심 액션이자 유입 미끼였으나, 실제로 별도 랜딩/폼이 구축됐는지 자료상 미확인. (현재는 리틀리 프로필 + 오픈채팅 고정공지 구조)
- ⚠️ **릴스 퍼널 / 인스타·유튜브 콘텐츠 발행**: GTM 채널 계획은 있으나 실제 발행·측정 여부 미확인
- ⚠️ **구독(SaaS) · 부적 업셀**: 미출시. 기획안 로드맵상 M1(수익 이원화)·애드온으로 후순위 배치와 정합
- ⚠️ **PMF 1차 검증지표**(무료→유료 전환율 / 객단가 / Q&A·재구매율 / 검토 1건 소요시간): 실측 데이터 확보 여부 미확인 — 런칭 후 보정 필요

## 4. 유지된 것 (방향 일치 확인)

변경점만큼 중요한 건 **핵심 가설이 흔들리지 않았다**는 점입니다:

- 하이브리드 정체성(**AI 초안 + 전문가 감수 + 음성 + 후속 Q&A**) 그대로
- **감수 처리량 = 매출 상한 단일 병목**이라는 진단 유지 → 그래서 할인을 엔트리에만 태우고 코어 병목을 보호
- "예언 아님 · 참고/심리정리" 법적 프레이밍, 전상법 환불규정, 무노출 운영(얼굴·목소리 비공개) 유지
- 업셀 사다리 개념(엔트리→코어→구독→부적) 유지, 다만 **뒤 두 칸은 시점을 미룸**
