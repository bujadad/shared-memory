# 미타스야 2027(1년차) 연매출 확률 밴드 — 두 봇 공통 확정 기준

> 2026-07-25 확정. 젠슨(OpenClaw)·헤르메스(Elon Musk) 산정 수렴 + 부자아빠님 승인.
> 이후 모든 미타스야 IRR/재무 계산은 **base 6.0억 기준**으로 통일한다. 7.2억은 upside로 별도 표기.

## 확정 확률 밴드 (2027, 1년차)
| 시나리오 | 확률 | 연매출 |
|---|---|---|
| downside (비관) | 15% | 5.4억 |
| **base (passive)** | **25%** | **6.0억** ← IRR 기준 |
| semi-active | 32% | 6.5억 |
| upside (active 성공) | 40% | 7.2억 (별도 표기) |
| 극상 | 12% | 8.0억+ |

- passive 20~25% / active(가속 성공) 40% — 젠슨(22% / 40~45%)·헤르메스(정정 후) 수렴.
- 기존 헤르메스 50~60%는 **오류 인정·정정**. 사유: ①램프업 거의 미반영 ②가속전략 성공을 암묵적 기본값으로 가정 ③첫해 OTA 평점 0에서 ASP 방어 난이도 미반영.

## 램프업 곡선 (헤르메스 재산정, 공통 채택)
- 2~3월 OCC 55~60% → 4~5월 65~68% → 6~7월 72~74% → 8~10월 75~77% → 11~12월 73~75%
